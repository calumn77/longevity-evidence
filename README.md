# Longevity Evidence — first website prototype

A lightweight static website with a homepage, searchable evidence library, senolytics profile and research briefing.

## Preview
Open `index.html` in a browser. Navigation works without a build step.

## Publish with GitHub Pages
Upload these files to the root of your GitHub repository, then open Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, and save.

Scientific content is a provisional draft and should be verified before public publication.

## Version 0.2
Visual redesign with a responsive editorial layout, original SVG artwork and no external image hosting. Fonts use Google Fonts with local fallbacks. Upload all HTML, CSS and the entire `assets` folder to the repository root.
